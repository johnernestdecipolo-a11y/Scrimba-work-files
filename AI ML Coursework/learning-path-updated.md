# Free Learning Path: Web Dev First, Then AI/ML (Updated)

All free. Skip paid certificates for now. Links are unverified, so search the name if one breaks. Course contents change, so skim each syllabus before you start.

**What changed from the previous version**
- Added **TypeScript**, **backend/API basics**, **Tailwind CSS**, **testing basics**, and a **portfolio and resume** step.
- Moved **freelance and job applications** earlier, right after you have 2-3 deployed projects, so you can earn while you keep learning.
- SQL, AI features, and DSA now run in parallel with job hunting instead of blocking it.
- Trimmed the AI step to a lean first pass.

**When to start applying:** after step 11 (portfolio and resume). Don't wait to finish everything.

---

1. **Python:** Scrimba Learn Python (free tier): https://scrimba.com
   * Finish it first.

2. **Git and GitHub:** https://learngitbranching.js.org and https://github.com
   * Learn Git Branching: the Introduction Sequence and Ramping Up levels.
   * GitHub: repos, commits, branches, pull requests, and a README for every project.

3. **HTML/CSS (done):** https://www.freecodecamp.org/learn
   * Responsive Web Design: already completed on freeCodeCamp.
   * Skim The Odin Project's HTML/CSS lessons only if you hit gaps while building.

4. **JavaScript:** https://www.theodinproject.com
   * The Odin Project: the JavaScript basics in Foundations, then the JavaScript course. Build its projects.
   * Skip Odin's HTML/CSS lessons since you've done them on freeCodeCamp.
   * Use https://javascript.info as a free reference when a lesson is unclear.
   * Optional extra practice: Scrimba's Learn JavaScript (https://scrimba.com) if it's in the free tier.

5. **TypeScript (new):** https://www.typescriptlang.org/docs/handbook/intro.html
   * The official handbook: basic types, interfaces, functions, and generics (the basics only).
   * Most Next.js jobs and tutorials use it, so learn it before or alongside React.

6. **React:** https://www.theodinproject.com and https://react.dev/learn
   * The Odin Project: the React course only. Skip the rest of its path.
   * Official React docs (react.dev/learn): keep them open as a free reference.
   * Take this right after Odin's JavaScript course, since it assumes you know it. Same site, so you stay in one flow.

7. **Next.js and Tailwind CSS:** https://nextjs.org/learn and https://tailwindcss.com/docs
   * The main Learn Next.js course (the dashboard app), after React.
   * Tailwind CSS (new): learn it as you go with the official docs. The Next.js tutorial uses it, and it's common in real projects.

8. **Backend and API basics (new):** https://www.freecodecamp.org/learn and https://www.theodinproject.com
   * The Odin Project's Node.js course (Express, databases, authentication), since you're already using Odin. freeCodeCamp's Back End Development and APIs is an alternative.
   * Build one small project with your own API: create, read, update, and delete data, plus a simple login.

9. **Testing basics (new):** https://vitest.dev
   * Write a few unit tests for one of your projects (Vitest, or Jest if your project uses it).

10. **Deploy projects free:** https://vercel.com
    * Deploy every Next.js project. Check its terms for commercial use before doing client work.

11. **Portfolio and resume (new):**
    * Build a simple portfolio site with 2-3 deployed projects, each with a live link, a GitHub link, and a short description of what you built and what problem it solves.
    * Write a one-page resume, leading with projects and results, not courses.
    * Update your GitHub profile (pin your best 3 projects) and LinkedIn.

12. **Freelance and jobs (start here, don't wait for the rest):**
    * https://www.onlinejobs.ph
    * https://www.jobstreet.com.ph
    * https://www.linkedin.com/jobs
    * Make a profile with your GitHub projects and read real postings to see which skills they ask for.
    * Check your employer's rules first if you already have a job.

*From here, steps 13-15 run in parallel with job hunting.*

13. **SQL:** https://www.kaggle.com/learn and https://roadmap.sh/sql (plus https://www.freecodecamp.org/learn if you have time)
    * Kaggle: Pandas, then Intro to SQL (Advanced SQL if you want more).
    * roadmap.sh/sql: use it as a checklist.
    * Optional: freeCodeCamp's Relational Databases cert (SQL, Bash, Git). It's long, so skip it if time is short.

14. **Add AI features:**
    * **First pass (start with these two):**
      * Anthropic Academy, Building with the Claude API: https://anthropic.skilljar.com/claude-with-the-anthropic-api
      * Hugging Face LLM Course: https://huggingface.co/learn/llm-course
    * **Then, as you need them:**
      * Anthropic Academy:
        * Claude Platform 101: https://anthropic.skilljar.com/claude-platform-101
        * Introduction to Model Context Protocol: https://anthropic.skilljar.com/introduction-to-model-context-protocol
        * Optional intro: AI Capabilities and Limitations: https://anthropic.skilljar.com/ai-capabilities-and-limitations
      * Hugging Face:
        * Agents Course (after the LLM course): https://huggingface.co/learn/agents-course
        * Open-Source AI Cookbook (reference): https://huggingface.co/learn/cookbook
      * LangChain Academy (Build category): https://academy.langchain.com/collections/build
        * Introduction to LangChain - Python or Introduction to LangGraph - Python
        * Then Quickstart: LangSmith Essentials: https://academy.langchain.com/courses/quickstart-langsmith-essentials
        * Skip the paid certification exam.
    * **Project:** add an AI feature (for example, a chatbot or document Q&A) to one of your deployed web apps.

15. **DSA and coding practice (a few problems a week in the background; continue during your CS degree), in this order:**
    * Runestone: https://runestone.academy/ns/books/published/pythonds3/index.html
      * Big-O analysis, basic data structures (stacks, queues, lists), recursion, sorting and searching, trees, graphs.
    * NeetCode (free roadmap and videos): https://neetcode.io
      * Arrays & Hashing, Two Pointers, Stack, Binary Search, Sliding Window, Linked List, Trees; then Heap, Backtracking, Graphs, 1-D DP.
    * LeetCode (free problems): https://leetcode.com
      * Easy problems first, matched to the NeetCode topic you just studied.
    * MIT OpenCourseWare 6.006 (later): https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/
      * Only the lectures on topics you're stuck on (hashing, trees, heaps, graph search, dynamic programming).
    * Codeforces (last): https://codeforces.com
      * Div. 3 and Div. 4 contests.

16. **ML basics (free, during your CS degree):**
    * Kaggle Learn: https://www.kaggle.com/learn (Intro to ML, then Intermediate ML)
    * Google Machine Learning Crash Course: https://developers.google.com/machine-learning/crash-course (all of it)
    * Harvard CS50 AI (optional, later): https://cs50.harvard.edu/ai/

## Suggested Order at a Glance

| Stage | Steps | Goal |
|---|---|---|
| Foundations | 1-4 | Python, Git, HTML/CSS, JavaScript |
| Web dev skills | 5-9 | TypeScript, React, Next.js and Tailwind, backend/API basics, testing |
| Get hireable | 10-12 | Deploy, portfolio and resume, start applying and freelancing |
| Parallel growth | 13-15 | SQL, AI features, DSA practice |
| During your degree | 16 | ML basics |

## Notes

- Projects matter more than certificates. Aim for 2-3 deployed projects before you apply.
- If time is short, shrink the AI step to the first pass (two courses) and do the rest later.
- Re-check this list every few months against real job postings, and drop whatever isn't helping.
